# Installation

SineVFX is a Roblox Studio **plugin**. There are two ways to get it, depending on how you
want to pay.

## Option 1: Creator Store (recommended)

**[Get it on the Creator Store](https://create.roblox.com/store/asset/96645663824840/SineVFX)**
- buy once, and it installs straight into Studio.

Because it's bought through the Roblox Creator Store, it installs and **updates itself**
right inside Studio. No extra steps.

1. Open the [Creator Store listing](https://create.roblox.com/store/asset/96645663824840/SineVFX).
2. Buy it.
3. It appears in Studio automatically.

## Option 2: Buy the shirt (pay with Robux)

**[Buy the SineVFX shirt · 3000 Robux](https://www.roblox.com/catalog/138288042903286)** -
pay with Robux, then verify in Discord to receive the plugin.

1. Buy the shirt on Roblox with your 3000 Robux.
2. Join the [Discord](https://discord.gg/krQE8tGsUz) and open the **Buyer Role** post.
3. Hit **Connect**, sign in with Roblox, and the bot verifies your purchase.
4. You get the Buyer role and the plugin file. Done.

::: warning The shirt version does not auto-update
The shirt version is a **local plugin**, so it does not auto-update like the Creator Store
one. To get it you must join the Discord and verify, and you'll re-download the file for
future updates.
:::

## Enable it in Studio

1. Open **Roblox Studio**.
2. Go to the **Plugins** tab in the ribbon.
3. Click the **SineVFX** button to launch it.

The SineVFX toolbar button opens the plugin, and its floating controls appear in the
viewport. From there, head to the [Quick start](/quick-start).

## Updating

- **Creator Store:** updates apply automatically.
- **Shirt version:** grab the latest file from the Discord when a new version ships.

If the UI ever looks broken after an update, fully **disable and re-enable** the plugin (or
restart Studio) to clear Studio's module cache. See
[FAQ & troubleshooting](/faq).

## Requirements

- Roblox Studio (current version).
- A place you have edit access to.

No external dependencies.
