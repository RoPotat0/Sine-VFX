# Shifter

**Shifter** slides a single property up or down across a whole multi-selection at once, with a
slider. It's the fastest way to nudge one value (brightness, a size, a speed) consistently
across many effects.

## Using it

1. Select the transformed effects you want to change (emitters, trails, and/or beams).
2. Open **Tools → Shifter**.
3. Pick the property and drag the slider. Every selected effect shifts together, live.

Because Shifter keys each object by kind, a mixed selection of emitters, trails, and beams is
handled correctly, each shifted through its own settings.

## When to use it

- Making a group of effects a bit brighter or dimmer.
- Bumping a shared size or speed across a scene of effects.
- Any time you'd otherwise edit the same property on many objects one by one.
