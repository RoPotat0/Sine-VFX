# Installation

SineVFX is a Roblox Studio **plugin**. Once installed it lives in your Studio toolbar and
is available in every place you open.

## Get the plugin

1. Open the SineVFX page on the **Creator Store** (linked from
   [sinevfx.xyz](https://sinevfx.xyz)).
2. Click **Install** (or **Get** / **Buy**, depending on the listing).
3. Roblox adds it to your account's plugins automatically.

::: tip
If you own it already, it will show up under **Toolbox → Inventory → My Plugins** inside
Studio.
:::

## Enable it in Studio

1. Open **Roblox Studio**.
2. Go to the **Plugins** tab in the ribbon.
3. Click the **SineVFX** button to launch the plugin.

The first thing you'll see is the **Hub** — a small floating button (the FAB) in the corner
of the viewport. Everything in SineVFX opens from there. See [The Hub](/windows/overview).

## Updating

Plugins installed from the Creator Store update automatically when a new version is
published. If an update seems stuck or the UI looks broken after one, fully **disable and
re‑enable** the plugin (or restart Studio) to clear Studio's module cache — see
[FAQ & troubleshooting](/reference/faq).

## Permissions

SineVFX runs entirely inside Studio and edits the effects in your place. Depending on your
setup Studio may ask for **script injection** permission the first time you plant the
[runtime module](/shipping/module) — that's what lets SineVFX write the effect module into
your game. Grant it if you want to play effects back at runtime.

## Requirements

- Roblox Studio (current version).
- A place you have edit access to.

That's it — no external dependencies, no separate downloads.
