# Copier

**Copier** works like the [Shifter](/tools/shifter), but with **Copy / Paste** instead of a
slider. Copy a property (or set of them) from one effect and paste it onto others, to propagate
a look across many objects.

## Using it

1. Select the source effect and **Copy** the property you want.
2. Select the target effects.
3. **Paste**, and they take on the copied value.

Like the other tools, Copier keys each object by kind (emitter / trail / beam), so pasting
across a mixed selection lands each value in the right place.

## When to use it

- Matching one effect's settings onto a batch of others.
- Standardising a value across a scene without retyping it.
- Propagating a tweak you dialed in on one effect.
