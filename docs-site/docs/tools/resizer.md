# Resizer

**Resizer** scales an effect **proportionally**. Instead of editing size channels one at a
time, it multiplies all of an effect's size-related properties together, so the effect grows or
shrinks as a coherent whole and keeps its look at the new scale.

## Using it

1. Select the transformed effects to scale.
2. Open **Tools → Resizer**.
3. Set the scale factor. Every size channel is multiplied together across the selection.

## When to use it

- Fitting an effect to a bigger or smaller object.
- Making a whole effect read at a different distance without redialing each size by hand.
- Scaling a multi-part effect uniformly.
