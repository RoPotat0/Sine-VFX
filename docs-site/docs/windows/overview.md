# The Hub

Everything in SineVFX opens from the **Hub** — a small floating button (the **FAB**) that
lives in a corner of the Studio viewport. It's always there, always on top, and never gets
in the way of your work.

## The FAB and menu strip

Click the FAB to **expand** a strip of buttons beside it. Click it again to collapse. The
strip holds the six top‑level entries:

| Button       | Opens / does                                                            |
| ------------ | ----------------------------------------------------------------------- |
| **Emit**     | The [Emit window](/windows/emit) — emit particles (hold to repeat).     |
| **Library**  | The [Texture Library](/windows/library) — browse textures and apply them to selected emitters. |
| **Tools**    | The [Tools menu](/tools/overview) — Shifter, Resizer, Retimer, Copier, Code, Color. |
| **Paths**    | Toggles [predicted particle paths](/windows/paths) for the selected emitters. |
| **Module**   | The [Module window](/shipping/module) — plant the runtime for in‑game VFX. |
| **Settings** | [Settings & themes](/reference/settings).                               |

An active entry is highlighted so you always know what's open.

## Moving the Hub

The FAB can sit in any corner. Change it under **Settings → Button Layout** (bottom‑right by
default). Its position, whether the strip is expanded, and which windows were open all
**persist between sessions** — reopen Studio and you're right where you left off.

## Windows in general

SineVFX windows are floating, draggable, and resizable. A few shared behaviours:

- **Drag** the title bar to move; drag an edge/corner to resize.
- **Pin** (where available) keeps a window from being dismissed when you click away.
- **Close** with the × in the title bar.
- Positions and sizes are **remembered** per window.

Read on for each window in turn, starting with [Transform](/windows/transform) — the first
thing you do to any effect.
